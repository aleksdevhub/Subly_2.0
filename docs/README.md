# Subly — Telegram Mini App

Эта папка — версия Subly для Telegram (бот → кнопка → мини-приложение).
Сервера нет: логика из C# перенесена в `js/store.js`, а данные каждого пользователя хранятся
в облаке Telegram (CloudStorage). Если открыть страницы в обычном браузере — данные сохранятся в браузере.

Папку раздаёт бесплатно **GitHub Pages**: Settings → Pages → Branch `master`, папка `/docs`.
Адрес: `https://aleksdevhub.github.io/Subly_2.0/`
